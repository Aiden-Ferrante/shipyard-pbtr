# v0.19.0 — Consolidation

Sub-cycle under the **The Face** super-cycle (`GOAL PROMPT — The Face (v0.19.0 → v0.23.0)`)
Opened and closed 2026-08-14 · appetite: one evening

## Problem

`ui.jsx` exported 22 components and 5 of 16 view files imported it. Two `Chip`s existed with
different tone maps and different shapes; status rendered three ways; nine views hand-rolled their
own loading text while `<Loading>` sat unused. Nothing looked wrong in isolation — the app simply
rendered the same concept differently depending on which file you were in, and that inconsistency
*is* the sensation of an unfinished tool.

## Appetite

One evening. Appetite decided the ratchet (below) rather than a 169-site refactor.

## What was done

Four commits, each green on build + suite:

1. `b6d21db` — one `Chip`, one status renderer, one `Skeleton`
2. `e8da4de` — every loading state from `<Loading>`, which gained an `inline` variant
3. `59f969b` — `check-ui.mjs`, `make check`, and a pytest contract case
4. `c256c30` — the accent means interaction, nothing else

## What the checker found

The first run reported **169 violations, all of a single rule**. Every structural rule passed on
the first try: no view redefined a primitive, `kit.jsx` owned none, no hand-rolled loading text
survived, no raw colours, `ui.jsx` pure. The consolidation was structurally complete before the
checker existed — what remained was 169 raw font sizes bypassing the six-step scale.

126 of them were `text-[11px]`, and `--text-micro` is exactly `0.6875rem`. That substitution is
provably zero-change, so it was made. The other 43 have no exact equivalent — `10px` sits below
the scale and `13px` between two steps — so converting them is a visual judgment, not a mechanical
one. Rule 5 became a **ratchet at baseline 43**: the count may fall, never rise.

## The retro item worth keeping

**A checker with no negative test is decoration, and this proved it inside an hour.** The first
draft of the raw-colour rule skipped any line containing `//`. A colour literal with a trailing
comment therefore passed clean. It was caught only because the planted-violation fixture expected
three failures and received two. Had the fixture not existed, the rule would have shipped looking
green and enforcing two-thirds of itself.

## Deviation from the plan

The commit ladder in the goal prompt orders the checker (4) after routing the remaining views (3).
That was inverted deliberately: building the checker first meant the routing work could be verified
mechanically instead of by eye — and it then showed the routing was already structurally done,
which reading the files would not have established with the same confidence.
