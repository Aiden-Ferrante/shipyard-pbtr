# v0.21.0 — The sweep, first pass

Closed 2026-08-14. **Not a planned sub-cycle** — this is the honest label. It began as an audit
and became a body of work; there was no Plan phase before the first commit, and the cycle record
is written after rather than the plan before. Recorded that way so the tag is not read as a
completed arc.

## What drove it

Two read-only audits of shipyard's own surface — every backend route tagged PRUNE/KEEP/ENHANCE,
every frontend view checked for reachability, dead code, drift and missing states. The findings
are in `SWEEP — prune, keep, enhance.md`.

## What shipped

Correctness first, then dead code. Ten commits, green at every one.

The most important is `a4255e1`. Four project panels converted a failed fetch into confident prose
asserting the opposite — the app said *"the tag and the code agree"* when it had no idea. That is
worse than a missing state, and worse than the `{"build": true}` → 200 hole fixed in v0.20.0,
because it was already user-visible. It is the same failure this super-cycle's guardrail names:
*confidently wrong is worse than unsure.*

`fb600e8` is its render-time twin. A throw inside a subtree leaves a blank pane recoverable only
by reload — indistinguishable from an empty chart, and the reason the vanishing graph has resisted
diagnosis: no console error survives, because the failure is in render, not in a fetch.

## The retro item that matters

**Eight claims acted on today did not survive verification.** Six came from the audits: two of the
four v0.20.0 defects were wrong or already fixed; the "6 of 8 stranded functions" count was wrong;
the raw-font-size figures were ~3× overstated. Two were mine — I proposed a scoped-edge crash in
`graph.jsx` and a missing map guard, and `relations()` already guards exactly that at `:55`. I
described it as "the concrete throw path" having not read the function that would contain it.

The audits are worth having; roughly half their specifics hold. But the cost of checking is about
a minute and the cost of not checking is a wrong commit. **Verify before acting** is now the rule
for the ~40 remaining findings.

Second: two edits to `goals.jsx`-sized files broke the build, both from brace-matching a function
whose parameters are destructured. That is now written into the inspector plan's risk note.

## What is NOT done

Step B is half finished — `/api/drift` and the two `templates/{slug}` routes are equally dead, but
pruning them reds 9 tests that exercise real logic through those routes, and retargeting them is
not mechanical (`/api/drift` composed `chart.drift` **with** the uncharted list). Reverted rather
than leave the suite failing. Steps C–F untouched. Four zero-use `ui.jsx` components still there.

The vanishing graph is **still undiagnosed**. The boundary makes the next occurrence legible; it
does not fix it.
