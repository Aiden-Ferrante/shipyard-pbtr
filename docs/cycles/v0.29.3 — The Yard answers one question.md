# v0.29.3 — The Yard answers one question

Light cycle plan under [[0.) Development Protocol 1.0]]
Opened 2026-08-26

Addresses **The Yard answers one question: what may start next**

> The page shows the queue, the gate, and receiving, and nothing else; I open it to
> begin work at least weekly, rather than to look at it.

## Problem

The Yard carried eight bands. Three answered a question about the fleet — what is
held, what the gate refuses, what has not been adopted. Five measured the operator:
throughput, rework, portfolio counts, a commit heatmap, a hill position.

Two of those five measured nothing at all. `hill_snapshots` held **0 rows** and **0
problems** ever carried a `due` date, so the page was rendering two instruments that
had never taken a reading. The page built to start work had become a telemetry page
whose telemetry was never recorded, and it was not opened.

`stage` was the same failure a version further along. It was the dial
`standards.yaml` used to decide which bands of requirement a repo owed; that file was
deleted in **v0.5.0** and the field outlived its meaning by twenty-four versions,
rendering as a coloured word nothing read.

## Appetite

One sitting. Mostly deletion.

## Plan

Delete `line.py`, `cadence.py`, `hill.py` and every band that reads them; drop
`hill_snapshots`; remove `stage` end to end; put a cycle chip in the slot it leaves.
Keep the `bays` half of `/api/yard` — that is the gate's data.

**Non-goals.** No new measurement to replace what goes. If a number is wanted later
it can be added back with a reason.

## Exit criteria

The Yard renders queue, gate and receiving only. `/api/projects/{pid}/line` is gone.
No surface renders `stage`. `make test` and `make check` green.

## Build

**The plan said keep `bays` and delete the ledger, and did not notice they were the
same band.** `LedgerBand` grouped repos by *motion* and joined the bays in by id for
each strip's facts — so deleting it would have deleted the only place any repo
strip rendered, taking the gate's own detail with it.

What went back in its place is `YardBand`, recovered from `6641975~1`: the same
repos, in the bay that names what blocks them, underneath the gate band where the
422 can be read row by row. The ledger had *displaced* it in v0.29.0, replacing a
question about what may start with a question about who has been busy. Undoing that
is most of this cycle.

**The cycle chip takes the third column**, and its two states are the gate's two
answers: a count when nothing is running, `cycle open` when a record is in flight —
which is exactly when `_open_gate` refuses a second. It reads `planned`, not `open`,
so the chip and the 422 cannot disagree. `_cycle_counts` rides `_repo_facts`, the
TTL-cached bundle, because `repo.cycles()` shells git per repo and an uncached call
would run serially across all thirty-four manifests.

`StageChip` and `MaturityChip` collapsed into one `CycleChip`. They had been the
same component twice, fed by `main.py` aliasing `stage` to `maturity`.

**Deleted:** `line.py`, `cadence.py`, `hill.py`; `/api/projects/{pid}/line`,
`POST /api/hill`, `GET /api/hill/{repo}`; the `groups`/`heat`/`targets` keys;
`LedgerBand`, `PortfolioBand`, `RhythmBand`, `LineBand`, `Reach`, `Appetite`, the
inspector's Hill facet and `HILL_STOPS`; the `stage-spike/tool/product` colour
tokens; `tests/test_line.py` and `tests/test_line_band.py`. Eleven domain modules
became eight, and the star rule still holds over all of them.

**The 33 manifests in the fleet keep their `stage:` lines.** A key nothing reads is
inert; a sweep would dirty thirty-three working trees at once and trip the review
gate fleet-wide for a cosmetic change. Shipyard's own manifest was rewritten because
this cycle was already touching it, and its description still advertised "stages,
checklists, links" — two of three now gone.

## Test

`make test` — **438 backend + 5 frontend, green.** `make check` clean; the raw
font-size ratchet did not rise.

The suite went red in eleven places on the first run, which is the useful part.
`test_shape_is_exactly_the_contract` caught both the removed payload keys and the
strip's changed third column — the test exists to catch a key nobody meant to ship,
and it caught three. `test_repo.py` caught `write_manifest`'s dropped parameter;
`test_board.py` caught the `maturity` alias. Nothing was found by reading.

**Driven in the served app** at :8847, rebuilt, with the running instance on :8845
left alone throughout:

- The map reads `THE QUEUE 6 → THE GATE 19 → RECEIVING 0`, and the flow sentence
  under it is the page's one question.
- The queue lists its six; the gate names the nineteen it would refuse; the bays
  below show `1 cleared to enter` and `26 owes work`, each strip carrying its
  blockers and a cycle chip.
- Cycle chips are real: `shipyard → 43 cycles`, `learn-hub → 11`, `stocklake → no
  cycles yet`.
- `/api/yard` returns exactly `{bays, queue, scanned}`.
- `/api/projects/shipyard/line` → **404**. `/api/hill/shipyard` → **404**.
- `/health` unchanged: `{ok, checks:{db, code_root, mc}, freshness}`.
- Board and project pages render the chip in the old stage slot. No console errors
  on any page.

Two bugs found this way and not by the suite, both from the header the deletion left
behind: `yard.carried` was a ledger key, so the page opened with *"carried of 34 on
disk"* — a blank where a number belonged; and the sentence beneath still claimed
*"only membership, hill and targets are stored"* after two of those three had been
deleted. Neither is reachable from a test that asserts a payload.

## Review

**The deletion was cheap because the measurement was honest.** Two row counts —
`hill_snapshots` at 0, `due` at 0 — turned "should we hide these or delete them"
into a decision with no downside. The instinct to preserve was worth exactly one
query.

**The band I had to restore is the finding.** v0.29.0 replaced the bays with a
motion ledger and called it a retitle; this cycle discovered they were different
questions wearing the same heading, and that the useful one had been the casualty.
The lesson generalises: a band that groups the same rows a different way is not a
refinement of the old band, it is a second band, and the first one leaves quietly.

**`stage` cost twenty-four versions of nothing.** The field was decorative from
v0.5.0 and nobody removed it because a coloured chip does not look like debt. The
gate now in front of it — a chart node, a waypoint, a closed cycle — is the kind of
thing worth colouring, and when standards return they get a dial that means
something on the day it ships.

**What carries forward.** ADR 0005 was written this cycle and covers D2 and D3 as
the goal prompt required; it names `chart.children()` as the seam — *composes work*
versus *is work* — that answered three separate questions across the arc. The
remaining child of this arc is `v0.30.0`, which closes the branch.
